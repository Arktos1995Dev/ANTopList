# Инструкция по запуску и развертыванию

### Локальный запуск

1.  **Установите зависимости:**
    Откройте терминал и выполните команду:
    ```bash
    npm install
    ```

2.  **Запустите сервер:**
    Эта команда запустит ваш сервер Node.js.
    ```bash
    npm start
    ```
    После запуска вы увидите сообщение о том, что сервер запущен, в консоли.

    **Перезапуск сервера:** Если вы внесли изменения в `server.js` или другие серверные файлы, остановите текущий процесс (обычно `Ctrl + C` в терминале) и снова запустите `npm start`, чтобы изменения вступили в силу.

3.  **(Опционально) Скачайте изображения:**
    Если вам нужно скачать изображения аниме, вам понадобится Excel-файл со списком названий. Затем выполните:
    ```bash
    node download-images.js
    ```
    Это создаст папку `images/` и файл `image-mapping.json`.

### Развертывание (деплой) в Firebase

Ваш проект настроен для развертывания в Firebase Hosting.

1.  **Установите Firebase CLI:**
    Если у вас еще не установлен Firebase CLI, выполните:
    ```bash
    npm install -g firebase-tools
    ```

2.  **Аутентификация в Firebase:**
    ```bash
    firebase login
    ```

3.  **Инициализация Firebase (если еще не сделали):**
    ```bash
    firebase init hosting
    ```
    В процессе настройки укажите следующие параметры:
    *   **What do you want to use as your public directory?** `.` (точка)
    *   **Configure as a single-page app (rewrite all urls to /index.html)?** `Yes`

4.  **Развертывание:**
    Выполните команду для развертывания:
    ```bash
    firebase deploy
    ```

После выполнения этих шагов ваше приложение будет доступно по URL-адресу, предоставленному Firebase.
