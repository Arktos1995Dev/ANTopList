# Инструкция по скачиванию изображений

## Установка

1. Убедитесь, что у вас установлен Node.js (версия 14 или выше)
2. Установите зависимости:

```bash
npm install
```

## Использование

### Шаг 1: Скачивание изображений

1. Поместите ваш Excel файл (.xlsx или .xls) в корневую папку проекта
2. Запустите скрипт для скачивания изображений:

```bash
npm run download
```

или

```bash
node download-images.js
```

Скрипт:
- Создаст папку `images/` с изображениями
- Создаст файл `image-mapping.json` с соответствием названий и файлов
- Покажет статистику скачивания

### Шаг 2: Запуск веб-сервера

После скачивания изображений запустите веб-сервер:

```bash
npm start
```

или

```bash
npm run server
```

Сервер запустится на `http://localhost:8000`

### Шаг 3: Откройте веб-приложение

Откройте в браузере: `http://localhost:8000`

Веб-приложение автоматически использует локальные изображения из папки `images/`, если они есть.

## Что делает скрипт

1. Ищет Excel файл в текущей директории
2. Читает колонку "anime" (без учета регистра)
3. Для каждого уникального аниме получает изображение через Jikan API
4. Скачивает изображения в папку `images/`
5. Создает файл `image-mapping.json` с маппингом названий аниме на имена файлов

## Результат

- Папка `images/` с скачанными изображениями
- Файл `image-mapping.json` с соответствием названий и файлов
- Статистика скачивания в консоли

## Примечания

- Скрипт делает задержку 500ms между запросами для соблюдения лимитов API (3 запроса в секунду)
- При ошибке 429 (Too Many Requests) скрипт автоматически повторяет запрос с экспоненциальной задержкой (до 3 попыток)
- Изображения сохраняются с безопасными именами файлов
- Если изображение не найдено, оно пропускается с сообщением об ошибке
- Если вы получаете много ошибок 429, увеличьте задержку в коде (строка с `setTimeout(resolve, 500)`)
